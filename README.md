# DSA in Java – Part 06: ArrayList

This repository contains my Java implementations and practice programs focused on **ArrayList**, an important part of Java Collections Framework.

## 📚 Topics Covered

- Introduction to ArrayList
- ArrayList Creation and Initialization
- Adding Elements
- Accessing and Updating Elements
- Removing Elements
- Iterating Through ArrayList
- Searching Elements
- ArrayList Methods
- Practical Problems Using ArrayList

## 🛠️ Technologies Used

- **Language:** Java
- **IDE:** VS Code
- **Concepts:** Java Collections Framework, ArrayList, Loops, Methods

## 🎯 Learning Objectives

- Understand the working of ArrayList.
- Learn dynamic array operations in Java.
- Practice insertion, deletion, searching, and traversal.
- Strengthen Java programming and DSA fundamentals.
